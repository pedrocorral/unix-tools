| `fs/` | Test specifications for Tier 2 BSD filesystem utilities (`TS-FS-001`, `TS-FS-002`, `TS-FS-003`) | Implementing or testing `FS` domain |
| `proc/` | Test specifications for Tier 3 BSD process, DAG build & shell utilities (`TS-PROC-001`, `TS-PROC-002`) | Implementing or testing `PROC` domain |
| `sec/` | Test specifications for Tier 4 OpenBSD security & privilege utilities (`TS-SEC-002`) | Implementing or testing `SEC` domain |
