# Glossary

| Term | Definition | Domain code |
|---|---|---|
| BSD Text & Table Filters | Pure stream, sequence, and matrix-reshaping utilities (`jot`, `rs`, `lam`, `vis`, `unvis`) | `FILTER` |
| BSD Filesystem & Hierarchy Tools | Directory listing, boolean tree search, and declarative hierarchy auditing (`ls`, `find`, `mtree`) | `FS` |
| BSD Process, Build & Shell Tools | Command batching, DAG build automation, and POSIX/BSD command interpreter (`apply`, `make`, `sh`) | `PROC` |
| BSD Security & Privilege Tools | Rule-based privilege escalation and configuration auditing (`doas`, `doas.conf`) | `SEC` |

Domain codes are UPPERCASE, ≤ 8 chars, and name folders in `docs/requirements/functional/` and `docs/tests/`.
